# Event tooling v2: 32-byte selective capture — design

Date: 2026-09-30. Status: approved in chat (owner).
Scope: clean up the last v1 4-byte event concepts and rebuild the
capture/insert/generate loop on native 32-byte keys, with popularity-gated
selective capture. No decode-path changes (`event/registry.go`,
`event/event.go` untouched).

## 1. Background

v2 decodes logs keyed by the full 32-byte `keccak256("Name(type,...)")`
(`event/registry.go:sigKeyOf`). Two remnants still speak v1's 4-byte dialect:

- `tmp/events_registry.json`: 747 entries in `{selector, signature, name,
  inputs}` schema (`selector` = first 4 hash bytes as 8-hex).
- `event/builtin_gen.go`: `builtinSig4 map[[4]byte]*Definition`, re-keyed to
  32 bytes at `init()`; header still says "vendored for v2, regenerate from
  the v1 generator".

The three v1 commands (`event_abi_generator`, `event_abi_loader`,
`generate_event_builtins`) are already gone from the v2 tree. Nothing else
references them. `TestBuiltinTableCountAndKeys` proves
`keccak(signature)[:4] == selector` for all 747 entries, so migration is
lossless.

## 2. Decisions (owner-approved)

- D1 Single binary `cmd/eventtool` with `capture` / `insert` / `generate`
  subcommands (precedent: `cmd/docgen`).
- D2 `tmp/events_registry.json` migrated **in place** to the 32-byte schema;
  no 4-byte field retained.
- D3 `event/builtin_gen.go` regenerated to `map[[32]byte]*Definition` now.
- D4 Caller = **transaction sender** (tx owner joined by txid), threshold
  **≥10 distinct senders**, window **rolling 24h** back from the tip,
  sub-threshold contracts **skipped entirely**.
- D5 Gate/payload split: the caller count only **gates** a contract; once
  gated, `capture` ingests the contract's **entire ABI** (all event entries),
  not just caller-triggered events.
- D6 Store stays additive across periodic runs (upsert-if-absent, first-wins).

## 3. Corpus migration (`tmp/events_registry.json`)

New schema per entry: `{sighash, signature, name, inputs}`.

- `sighash` = lowercase hex of `keccak256(signature)`, 64 chars, no `0x`.
- `signature` / `name` / `inputs` unchanged (`inputs`: `{type, indexed,
  name}`).
- Migration is a pure function: recompute from `signature`, assert the first
  4 bytes equal the old `selector`, fail loud on any mismatch. The tuple /
  `trcToken` entries hash their literal stored type strings — same input the
  v1 generator used, so derivation is exact.
- `generate` and `insert` verify `sighash == keccak256(signature)` on load and
  reject mismatches; the file can never silently drift from
  `event/registry.go:sigKeyOf` again.
- `store.Load` accepts only the new schema; an old `selector` file gets an
  explicit "migrate first" error, never silent reinterpretation.
- `tmp/abi/` (7 seed files) is kept as the seed corpus.

## 4. `builtin_gen.go` re-key

- `builtinSig4 map[[4]byte]*Definition` becomes
  `builtinSig map[[32]byte]*Definition`, keys as 32-byte array literals,
  entries sorted by sighash hex for stable diffs.
- `init()` keeps insert-if-absent `registerBuiltin` semantics
  (order-independent: 747 distinct signatures).
- Provenance header rewritten: generated by `cmd/eventtool generate` from
  `tmp/events_registry.json`; the v1-vendored wording is removed.
- `event/builtin.go` (explicit TRC-20 pair) untouched — it already derives
  keys from definitions.
- `event/registry.go` `registerBuiltin` doc comment updated (no more
  "generated entry stored under a selector" wording).

## 5. `cmd/eventtool`

One `main.go` + `store.go`. Dependencies: stdlib + `tronlib.Dial` /
`rpc.GetBlockByNum2` / `rpc.GetTransactionInfoByBlockNum` / `rpc.GetContract`
+ `golang.org/x/crypto/sha3`. No global-registry side effects in the tool.

Shared store: `map[sighash-hex]SavedEvent` with `Load` (new schema only),
atomic `Save` (tmp + rename), `Upsert` (insert-if-absent, returns bool).

### 5.1 `capture [--node=grpc://127.0.0.1:50051 --out=tmp/events_registry.json --min-callers=10 --sleep-ms=250 --workers=8]`

1. `Dial`, `ChainTip` → tip `N`, wall-clock `T`.
2. Walk heights `N, N-1, ...`, fetching block AND infos per height (worker
   pool over heights, `--sleep` throttle between fetches), until
   `blockTimeStamp < T-24h` (timestamp cut-off, not a block-count estimate).
3. Join by txid: caller = tx owner (`TriggerSmartContract.owner_address`;
   other contract types by their owner field; unparseable txs skipped).
   Attribute each caller to the contract(s) the tx's infos/logs touch
   (`info.ContractAddress`, fallback `log.Address`). Tally
   `contract → distinct-owner set` in memory.
4. Qualifier iff `len(owners) >= --min-callers` (default 10). Below
   threshold: nothing — no ABI fetch, no write, no cross-run state.
5. Per qualifier, `GetContract` once → all event entries → canonical
   `Name(types…)` → full-hash upsert-if-absent (D5: whole ABI, D6:
   first-wins). Atomic save-on-insert; SIGINT/SIGTERM saves and stops.
6. Report: `heights / contracts seen / qualified / new events`. Exit 0.

Cost disclosure: ~2 RPCs/height (~57k per full 24h window). `--workers`
(default 8) bounds wall-time; the ABI fetch lands only on qualifiers.
Sampling (every kth block) is the documented fallback if a full window
proves too slow — out of scope for this change.

### 5.2 `insert [--in (required) --out=tmp/events_registry.json]`

v1 loader port. Reads an ABI file (raw array or `{"abi":[...]}`), minimal
local JSON parse (name + inputs only), canonical signature + full-hash
upsert. Prints `N new event(s) added`. Same sighash verification as §3.

### 5.3 `generate [--in=tmp/events_registry.json --out=event/builtin_gen.go]`

Reads the corpus (sighash-verified), dedups by sighash first-wins, emits
`event/builtin_gen.go` through `go/format` (replaces v1's hand-rolled
`bufio` + string escaping). Sorted output. Prints counts.

## 6. Tests

- Update `TestBuiltinTableCountAndKeys` to the new table shape: 747 entries,
  each key `== sigKeyOf(signature)`, keys distinct, each reachable in the
  global registry. The 4-byte prefix assertions are removed.
- New `cmd/eventtool` tests: store round-trip + first-wins + old-schema
  rejection; sighash derivation agreeing with the registry on fixtures
  (`Transfer(address,address,uint256)`,
  `SubmitTransaction(uint256,address,uint256,bytes)`); `generate`
  golden-output check (parses via `go/parser`, spot `go build` in CI).
- Gate sequence for the change: build → vet → `test -race ./event/
  ./cmd/eventtool/` → full suite → lint → `docgen -check`.

## 7. Docs

- `event/doc.go`: source-of-truth wording for the corpus + tool commands.
- `docs/runbook.md`: the three `eventtool` commands (flags, periodic-run
  recipe, fallback note).
- No `architecture.md` renumbering (section numbers are load-bearing for
  code comments); touch only if a section names the v1 generator.
